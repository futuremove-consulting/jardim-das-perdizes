# CTA único e mini formulário de qualificação

## Jardim das Perdizes Broker

## 1. Opinião executiva

A hipótese é boa, com uma correção essencial:

> **Um CTA principal único, sim. Um formulário genérico e igual para todos, não.**

A recomendação é usar **“Falar com especialista”** como a porta de entrada universal do site. O formulário começa com uma pergunta simples que identifica o papel do visitante e, a partir dela, apresenta apenas as opções relevantes.

O CTA único reduz dispersão, facilita reconhecimento da marca, concentra dados no CRM, simplifica testes e evita que a página pareça um conjunto de botões concorrentes. O roteamento interno, porém, deve preservar a diferença entre comprador, investidor, locatário, proprietário vendedor e proprietário locador.

A arquitetura fica assim:

```text
CTA público único: Falar com especialista
              ↓
Pergunta de roteamento
              ↓
Mini formulário contextual
              ↓
Lead classificado no CRM
              ↓
WhatsApp/e-mail + atendimento adequado
```

## 2. Melhor nomenclatura

### CTA universal

```text
Falar com especialista
```

É melhor do que “Entre em contato”, porque comunica valor e especialização. Também é melhor do que “Solicitar curadoria”, que é uma expressão interna e pouco natural para o visitante.

### Microcopy de apoio

> **Conte o que você procura ou o que precisa fazer. Vamos encaminhar você para o especialista certo em Jardim das Perdizes.**

### CTAs contextuais permitidos

O site pode ter um CTA universal e micro-CTAs coerentes com a página. Eles não são concorrentes; são atalhos que abrem o mesmo formulário com a intenção pré-selecionada.

| Contexto | CTA contextual | Intenção já preenchida |
|---|---|---|
| Card/ficha de imóvel | Agendar visita | Quero um imóvel > comprar para morar ou investir. |
| Lançamento | Conhecer o decorado | Quero um imóvel > conhecer projeto/decorado. |
| Ficha de tipologia | Ver imóveis compatíveis | Quero um imóvel > compra/aluguel. |
| Investimento | Solicitar estudo | Quero um imóvel > comprar para investir. |
| Conteúdo de venda | Descobrir quanto vale | Tenho um imóvel > vender. |
| Conteúdo de locação | Avaliar aluguel | Tenho um imóvel > alugar. |
| Artigo geral | Falar com especialista | Intenção ainda aberta. |

A regra é: **um CTA principal no header e CTAs contextuais nas páginas**, todos convergindo para o mesmo motor de qualificação.

## 3. Estrutura do mini formulário

### Tela 1 — pergunta principal

**O que você quer fazer?**

```text
( ) Quero encontrar um imóvel
( ) Tenho um imóvel
```

Essa pergunta é melhor do que começar por nome, telefone ou orçamento. Primeiro se entende a missão do visitante; depois se pede o contato.

### Tela 2A — para quem quer encontrar um imóvel

**O que você procura?**

```text
( ) Comprar para morar
( ) Comprar para investir
( ) Alugar para morar
( ) Conhecer um lançamento ou decorado
( ) Ainda estou pesquisando
```

### Tela 2B — para quem tem um imóvel

**O que você deseja fazer com seu imóvel?**

```text
( ) Vender meu imóvel
( ) Alugar meu imóvel
( ) Ainda estou avaliando
```

### Tela 3 — intenção prática

Para compra/aluguel:

```text
Qual é o próximo passo que você deseja dar?

( ) Receber imóveis compatíveis
( ) Agendar uma visita
( ) Conhecer um decorado
( ) Falar sobre condições e financiamento
( ) Solicitar um estudo de investimento
( ) Tirar dúvidas antes de decidir
```

Para proprietário:

```text
O que você precisa agora?

( ) Saber quanto vale
( ) Entender a faixa de aluguel
( ) Conhecer o processo da Broker
( ) Preparar o imóvel para venda/locação
( ) Falar com um especialista
```

### Tela 4 — contato

Campos recomendados:

```text
Nome
WhatsApp
E-mail — opcional na primeira versão
Melhor horário para contato
```

Checkbox obrigatório:

```text
[ ] Aceito ser contatado pela Jardim das Perdizes Broker sobre esta solicitação, conforme a Política de Privacidade.
```

Não pedir CPF, RG, renda, matrícula, endereço completo ou documentos na primeira conversão. Esses dados podem ser solicitados posteriormente, quando necessários e com finalidade clara.

### Tela 5 — contexto progressivo

Só depois da intenção e do contato, pedir os dados que melhoram o atendimento:

Para quem procura imóvel:

```text
Faixa de área
Dormitórios/suítes
Compra ou aluguel
Estágio: na planta, em construção, pronto novo ou revenda
Vista/sol
Faixa de orçamento — opcional
Prazo: imediato, 1–3 meses, 3–6 meses, pesquisando
Condomínio/produto de interesse — opcional
```

Para proprietário:

```text
Condomínio/produto
Venda ou locação
Tipologia/área
Estado do imóvel
Prazo
Expectativa de preço — opcional
Unidade completa — opcional e somente quando necessário
```

O formulário não deve transformar todos os campos em obrigatórios. A prioridade é obter um contato válido com intenção compreensível.

## 4. Versão mínima recomendada

Para começar, usar apenas três passos:

```text
1. Quero encontrar um imóvel / Tenho um imóvel
2. Comprar para morar / Comprar para investir / Alugar para morar / Vender / Alugar
3. Nome + WhatsApp + melhor horário
```

Depois do envio, abrir uma tela de refinamento opcional:

> **Quer nos ajudar a preparar melhor o atendimento?**

Área, quartos, estágio, condomínio, vista, sol e prazo aparecem como opcionais. Isso evita perder leads quentes por excesso de fricção.

## 5. Por que não usar apenas um botão “Falar conosco” sem qualificação?

Um botão sem qualificação gera volume, mas entrega pouco contexto. O corretor precisa descobrir novamente se a pessoa quer comprar, investir, alugar, vender ou alugar o imóvel. Isso aumenta tempo de resposta, reduz personalização e dificulta a análise de origem e qualidade dos leads.

O mini formulário resolve o problema sem criar um cadastro longo. A pergunta de intenção funciona como **roteador comercial**, não como barreira.

## 6. Benchmark brasileiro

### QuintoAndar

O QuintoAndar separa claramente Alugar, Comprar e Anunciar na navegação. Na captação de proprietário, usa uma promessa específica — “Anuncie seu imóvel grátis” — e organiza benefícios como calculadora de preço, visibilidade, fotos, tecnologia e corretores especialistas [1]. Na central de ajuda, diferencia proprietários, inquilinos, compradores e vendedores, além de indicar atendimento especializado e pessoa dedicada ao processo de compra e venda [2].

O aprendizado não é copiar a escala ou o modelo de aplicativo. É **ter uma porta simples e um roteamento claro por tipo de usuário**.

### Lopes

A Lopes separa Comprar e Alugar em abas, oferece busca por região/empreendimento, filtros por estágio, preço e área, além de “Fale conosco”, simuladores e conteúdos [3].

O aprendizado é manter as intenções comerciais visíveis, mas evitar multiplicar CTAs no primeiro viewport.

### Melhor prática brasileira sintetizada

| Elemento | Padrão recomendado |
|---|---|
| Entrada | Um CTA universal: Falar com especialista. |
| Roteamento | Duas categorias: Quero encontrar um imóvel / Tenho um imóvel. |
| Intenção | Compra para morar, compra para investir, aluguel para morar, venda, aluguel do próprio imóvel. |
| Contexto | CTA da página pré-preenche a intenção. |
| Formulário | 3 passos, 3–5 campos essenciais; refinamento opcional. |
| Atendimento | Especialista e mensagem adequados ao tipo de lead. |
| Canal | WhatsApp como opção de continuidade, não como único canal. |
| Confiança | Prazo de resposta, CRECI, privacidade e política de contato. |

## 7. Tela e microcopy recomendados

### Modal ou página

**Título:**

> Fale com um especialista em Jardim das Perdizes

**Texto:**

> Você está procurando um imóvel ou precisa vender/alugar o seu? Conte rapidamente o que deseja e vamos direcionar seu atendimento.

**Primeira escolha:**

```text
[Quero encontrar um imóvel]
[Tenho um imóvel]
```

**Mensagem de contato:**

> Recebemos sua solicitação. Um especialista entrará em contato pelo WhatsApp no horário informado.

Não prometer “atendimento imediato” se a operação não garantir isso. Se houver SLA real, informar algo como “retorno em até X horas úteis”.

## 8. Roteamento no CRM

### Classificação mínima

```text
lead_role: comprador | investidor | locatario | proprietario_vendedor | proprietario_locador
intent: morar | investir | alugar | vender | locar
next_action: visita | decorado | estudo | avaliacao | contato | conteudo
stage: frio | morno | quente
source_page
source_campaign
entity_interest
filters_selected
preferred_contact_time
consent_timestamp
```

### Lead quente

Priorizar quando houver:

```text
Agendar visita
Conhecer decorado
Condição/preço
Prazo imediato
Imóvel ou condomínio já definido
Solicitação de proposta
Reunião de investimento
Avaliação de imóvel com prazo
```

### Lead morno

```text
Receber imóveis compatíveis
Comparar tipologias
Entender custos
Estudar investimento
Avaliar preço sem prazo definido
```

### Lead frio

```text
Ainda pesquisando
Baixou guia
Assinou newsletter
Leu artigo sem ação comercial
```

O lead frio não deve ser tratado como oportunidade pronta para visita. Ele deve entrar em nutrição segmentada por intenção.

## 9. Formulário contextual por página

O mesmo motor deve mudar a pergunta inicial conforme a origem:

| Origem | Pergunta já pré-selecionada |
|---|---|
| Ficha de unidade | Você quer agendar uma visita ou receber informações? |
| Ficha de tipologia | Você quer encontrar imóveis com esta planta? |
| Ficha de condomínio | Quer conhecer este condomínio ou falar sobre alternativas? |
| Guia para investidor | Quer solicitar um estudo de investimento? |
| Guia de venda | Quer descobrir quanto vale seu imóvel? |
| Guia de locação | Quer avaliar o aluguel do seu imóvel? |
| Home | Você quer encontrar um imóvel ou falar sobre o seu imóvel? |

O formulário deve preservar a origem, a entidade e os filtros selecionados. Assim, o corretor recebe contexto sem o usuário precisar repetir toda a pesquisa.

## 10. WhatsApp, telefone e reunião

O WhatsApp é adequado para reduzir distância entre formulário e atendimento, mas deve ser acompanhado de registro no CRM. A mensagem pré-preenchida pode ser:

```text
Olá, sou [nome]. Quero [comprar para morar/comprar para investir/alugar/vender/alugar meu imóvel] no Jardim das Perdizes. Meu interesse é [contexto]. Meu melhor horário é [horário].
```

Para investidores e proprietários, oferecer também **Agendar uma reunião**, porque esses processos exigem mais contexto do que uma conversa rápida.

Para compra de alta intenção, oferecer **Agendar visita** imediatamente depois do envio. Para lançamento, oferecer **Conhecer o decorado**. Para proprietário, oferecer **Enviar dados para avaliação**.

## 11. Testes A/B prioritários

Não testar simultaneamente muitas mudanças. Sequência recomendada:

| Teste | Variante A | Variante B |
|---|---|---|
| CTA header | Falar com especialista | Encontre seu imóvel ideal |
| Hero | Falar com especialista | Ver imóveis e falar com especialista |
| Primeira pergunta | Quero um imóvel / Tenho um imóvel | Comprar / Alugar / Vender |
| Formulário | 3 passos | Uma tela curta |
| Continuidade | WhatsApp | WhatsApp + e-mail |
| Microcopy | Retorno em até X horas | Atendimento personalizado |

A métrica principal não deve ser apenas taxa de envio. Medir **lead qualificado, contato realizado, visita/reunião agendada e oportunidade criada**.

## 12. Recomendação final

A melhor solução para a Broker é:

```text
CTA universal: Falar com especialista

Primeiro roteamento:
Quero encontrar um imóvel | Tenho um imóvel

Segundo roteamento:
Comprar para morar | Comprar para investir | Alugar para morar
Vender meu imóvel | Alugar meu imóvel

Contato mínimo:
Nome | WhatsApp | melhor horário

Refinamento opcional:
Área | quartos | estágio | vista | sol | condomínio | prazo | orçamento

Próximo passo:
Visita | decorado | reunião | estudo | avaliação | seleção de imóveis
```

Essa abordagem é melhor do que espalhar “Agendar visita”, “Ver imóveis”, “Solicitar curadoria”, “Encontrar perfil” e “Falar conosco” como CTAs concorrentes no header. Ao mesmo tempo, não se deve eliminar os CTAs contextuais das fichas e páginas de alta intenção: eles devem abrir o mesmo fluxo, já contextualizado.

A formulação final recomendada é:

> **Fale com um especialista. Diga se você está procurando um imóvel ou precisa vender/alugar o seu. A Broker direciona o próximo passo: visita, decorado, reunião, estudo ou avaliação.**
